# Atividades da Aula 03 — JavaScript ES6+

Lista de exercícios da disciplina **Programação para Dispositivos Móveis — React Native**.

## Conteúdos praticados

- Template literals e destructuring;
- Spread, rest e módulos;
- Métodos de array: `filter`, `map`, `reduce` e `find`;
- Refatoração de ES5 para ES6+;
- Conversão de dados com `JSON.stringify` e `JSON.parse`.

## Organização dos arquivos

- `atividades.js`: exercícios dos quatro blocos;
- `matematica.js`: exportação nomeada da função `somar`;
- `app.js`: importação e uso da função `somar`;
- `package.json`: configuração para executar módulos ES6 no Node.js.

## Como executar

É necessário ter o Node.js instalado. No terminal, dentro da pasta do projeto, execute:

```bash
npm run testar
```

Também é possível testar separadamente:

```bash
npm run atividades
npm run modulos
```

Todos os exercícios estão identificados por bloco e número nos comentários do código.
